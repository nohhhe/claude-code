# Period Tracker - MVP 기능 명세서

> 여성 월경 주기 관리 서비스의 최소 기능 제품(MVP) 명세서입니다.

## 우선순위 정의

- **P0 (Critical)**: 서비스 핵심 기능, 없으면 서비스 불가
- **P1 (High)**: MVP에 반드시 포함되어야 하는 중요 기능
- **P2 (Medium)**: MVP 이후 추가 가능한 부가 기능

## 기능 목록

### 1. 사용자 인증 및 계정 관리

**우선순위**: P0
**예상 시간**: ✅ 완료 (4시간)

**사용자 스토리**:
```
As a 신규 사용자,

So that 내 월경 주기 데이터를 안전하게 저장하고 관리할 수 있다.
```

**수락 기준**:
- [x] 이메일 형식 유효성 검증

- [x] 회원가입 성공 시 자동 로그인

## 성공 지표 (Success Metrics)

MVP 성공을 측정하기 위한 핵심 지표:

1. **사용자 획득**
   - 목표: 100명의 가입자 (첫 달)
   - 측정: 회원가입 수

2. **사용자 참여도**
   - 목표: 주 3회 이상 접속
   - 측정: DAU/MAU 비율

3. **데이터 입력**
   - 목표: 사용자당 평균 3개 이상의 주기 기록
   - 측정: 주기 기록 수

4. **기능 사용률**
   - 목표: 달력 뷰 70% 이상 사용
   - 측정: 페이지 조회수

5. **사용자 만족도**
   - 목표: NPS 50 이상
   - 측정: 설문조사
