## ⭕ 개발 환경 구성
바이브 코딩에서 IDE 설정에 신경을 쓰는 건 약간 모순되는 것 같기도 합니다. 하지만 개발 환경을 관리하고 유지하는 건 일반적인 소프트웨어 엔지니어링 활동에 포함되어 있고 팀 차원에서도 관심도 계속 필요한 사항입니다.

### ◉ VS Code 설정
VS Code인데 설정 실습이지만 나는 IntelliJ를 사용함으로 해당 설정으로 찾음

IntelliJ는 .idea 폴더에 설정 파일들이 저장되는데, 보통 Git에서 제외하는 경우가 많아서 VS Code처럼 설정 파일 공유가 일반적이진 않음 굳이 한다면 아래 내용으로 작성 가능
> IntelliJ 설정 파일을 생성해줘
> - Run/Debug Configuration (실행/디버깅 설정)
> - Live Templates (코드 스니펫)
> - Code Style 설정
> - 추천 플러그인 목록

### ◉ 깃훅 설정
클로드가 깃훅을 자동으로 구성하여 코드 품질을 보장합니다. pre-commit에서 린트와 포맷팅, commit-msg에서 커밋 규칙 검증, pre-push에서 테스트를 자동 실행하도록 설정합니다. 이를 통해 일관된 코드 품질 기준을 유지할 수 있습니다.
> git hooks를 설정해줘
> - pre-commit: 린트와 포맷팅 체크
> - commit-msg: 커밋 메시지 규칙 검증
> - pre-push: 테스트 실행

#### ❓Playwright란?
웹 브라우저를 사람처럼 조작하고 검증할 수 있는 강력한 자동화 도구

마이크로소프트에서 개발했으며 최근 웹 개발 생태계에서 기존의 강자였던 Selenium이나 Puppeteer를 빠르게 대체하고 있는 차세대 도구

##### Playwright의 핵심 역할
- E2E(End-to-End) 테스트: 사용자가 웹사이트에 접속해서 로그인을 하고, 데이터를 입력하고, 결과를 확인하는 '전체 과정'을 코드로 자동화하여 테스트합니다.
- 브라우저 제어: Chrome(Chromium), Safari(WebKit), Firefox 등 모든 주요 브라우저 엔진을 하나의 코드로 제어합니다.
- 웹 크롤링: 사람이 직접 들어가기 어려운 복잡한 웹사이트(로그인이 필요하거나 JS로 로딩되는 페이지)의 데이터를 자동으로 수집합니다.
